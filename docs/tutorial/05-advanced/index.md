# 5. Scaling Up: Advanced Features and Capstones

Framed explicitly as "the toolkit doesn't change, only its ergonomics do." Also the one part of
the book explicitly designed to be enterable cold: a reader who already knows separation
logic/Iris (or who's willing to take Parts 1–4's core assertions on faith) should be able to
start at 5b or 5c directly. That's a deliberate tradeoff against the "one example grows across
the whole book" pitch from the [introduction](../index.md) — resolved by keeping backreferences
to *specific* earlier subsections rather than re-teaching them. Each of 5b/5c opens with a
one-line "Assumes" pointer naming exactly what's carried over from earlier parts; 5a doesn't need
one, since it's built entirely from Parts 1–4's own material, applied rather than extended.

  applied once, start to finish, including the first attempt that doesn't work.
